# Excalidraw Array Components

The custom library contains four reusable algorithm-diagram components:

- Empty indexed array
- Integer array
- String array
- Array with left and right pointers

Generate or refresh the library:

```bash
npm run excalidraw:arrays
```

With the local Excalidraw container running, download the library from:

<http://localhost:8080/custom-libraries/algorithm-arrays.excalidrawlib>

In Excalidraw, open **Library**, choose **Load library from file**, and select
`excalidraw/libraries/algorithm-arrays.excalidrawlib`.
